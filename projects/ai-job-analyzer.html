NLP & Career Tech

AI Job Skill Analyzer

Developed an AI-powered system designed to analyze job descriptions and map required skills to candidate profiles using Natural Language Processing (NLP) techniques.

Core Functionality

Building a bridge between talent and opportunity using intelligent skill extraction and matching algorithms. The system automates the tedious task of aligning resumes with complex job descriptions.

  • Skill Extraction: Leveraging NLP models to identify technical and soft skills from unstructured text.
  • Mapping Logic: Creating a scoring system to grade user profiles against job requirements.
  • Optimization: Helping candidates identify "skill gaps" to improve their employability.

Tech Stack

  • Python, FastAPI
  • NLP Transformers
  • React
  • PostgreSQL
