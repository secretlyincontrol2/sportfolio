Security & Automation

Owltech | Wema Hackathon

Automated security tool to detect high-risk "Shadow IT" apps and malicious URLs. Developed as a microservice for real-time threat detection.

Project Overview

Owltech was engineered to tackle the growing problem of unauthorized software (Shadow IT) in corporate environments. Developed during the Wema Hackathon, it aggregates data from multiple security sources to provide a unified risk assessment.

  • Microservice Architecture: Developed a FastAPI microservice aggregating real-time data from 5+ external security APIs.
  • Detection Engine: Automated scanning and categorization of URLs and applications based on risk profiles.
  • Scalability: Containerized with Docker for easy deployment on Render and cloud environments.

Tech Stack

  • Python, FastAPI
  • Docker
  • Render
  • Hugging Face Inference API
